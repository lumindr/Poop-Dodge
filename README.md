# 💩 Poop Dodge

하늘에서 떨어지는 똥을 피하며 최대한 높은 점수를 획득하는 간단한 웹 아케이드 게임입니다.

> 별도의 설치 없이 브라우저에서 실행되며, GitHub Pages 배포를 지원합니다.

## 🚀 실행하기

저장소의 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 개발 중에는 VS Code의 Live Server 같은 정적 파일 서버를 사용할 수도 있습니다.

## 🌐 GitHub Pages 배포

이 저장소에는 `.github/workflows/pages.yml` 배포 워크플로가 포함되어 있습니다.

1. GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**를 **GitHub Actions**로 선택합니다.
3. 변경 사항을 `main` 브랜치에 push합니다.
4. **Actions** 탭의 `Deploy to GitHub Pages` 작업이 완료될 때까지 기다립니다.
5. 배포된 게임은 `https://lumindr.github.io/Poop-Dodge/`에서 실행됩니다.

모든 파일은 상대 경로를 사용하므로 GitHub Pages의 프로젝트 하위 경로에서도 동작합니다.

플레이어는 좌우로 이동하며 떨어지는 똥을 피해야 합니다. 똥에 맞거나 스치면 즉시 게임이 종료되며, 게임이 종료될 때까지 피한 똥의 개수가 점수로 기록됩니다.

---

## 🎮 게임 개요

**프로젝트명:** Poop Dodge

**장르:** 2D 아케이드 / 회피 게임

**플랫폼:** Web Browser

**조작 방식:** 키보드 및 모바일 터치

### 게임 목표

하늘에서 무작위 위치로 떨어지는 똥을 최대한 많이 피하여 높은 점수를 기록하는 것이 목표입니다.

새똥을 제외한 일반 똥이 바닥까지 떨어질 때마다 **1점**이 증가하며, 그 누적 개수가 최종 점수가 됩니다.

---

## 🕹️ 조작 방법

| 입력      | 동작                 |
| ------- | ------------------ |
| `A`     | 1P 왼쪽 이동            |
| `D`     | 1P 오른쪽 이동           |
| `←`     | 1인용: 1P 왼쪽 / 2인용: 2P 왼쪽 이동 |
| `→`     | 1인용: 1P 오른쪽 / 2인용: 2P 오른쪽 이동 |
| `Space` | 게임 시작 / 다시하기 / 우산 사용 / 일시정지 해제 |
| `Shift` | 속도 아이템 사용 |
| `M`     | 효과음 켜기 / 끄기 |
| `R`     | 일시정지 또는 게임 오버 중 즉시 재시작 |
| `ESC`   | 게임 일시정지 / 일시정지 또는 게임 오버 중 홈으로 이동 |
| 마우스 클릭  | 게임 시작 / 다시하기 / 전체화면 전환 |
| 모바일 좌우 버튼 | 터치한 방향으로 이동         |
| 모바일 `⏸` 버튼 | 게임 일시정지 |

### 플레이어 이동

* 1인용의 1P는 `A`/`D` 또는 `←`/`→`로 이동합니다.
* 2인용에서는 1P가 `A`/`D`, 2P가 `←`/`→`로 이동합니다.
* 홈 화면에서 1인용과 2인용을 선택할 수 있습니다.
* 2인용에서는 한 명이라도 똥에 맞으면 게임이 끝나며 점수와 우산 사용권을 공유합니다.
* 플레이어는 게임 화면의 좌우 범위를 벗어날 수 없습니다.

## 🎯 게임 진행

### 1. 시작 화면

게임에 처음 접속하면 브라우저 전체 영역을 사용하는 시작 화면이 표시됩니다.

화면 중앙에서 1인용 또는 2인용을 고른 뒤 **게임 시작** 버튼으로 바로 시작할 수 있습니다.

기본 언어는 영어입니다. 화면 상단의 **LANGUAGE** 드롭다운에서 **한국어, English, 日本語, 中文**을 선택할 수 있습니다. 선택한 언어는 저장되며 홈, 게임, 일시정지, 게임 오버 화면 전체에 적용됩니다.

* **쉬움**: 처음에는 1개씩, 10점부터 2개씩 떨어집니다.
* **보통**: 더 빨라진 똥이 2개씩, 가끔 3개씩 떨어집니다.
* **어려움**: 더 크고 빠른 똥이 3~5개씩 무작위로 동시에 떨어지며 좌우로 크게 흔들립니다.
* **똥 지옥**: 똥이 6~9개씩 초고속으로 떨어지며, 이전 묶음이 남아 있어도 다음 묶음이 겹쳐서 떨어집니다.

게임 시작 전 `3 → 2 → 1 → 시작!` 카운트다운이 표시됩니다. 모든 게임은 쉬움에서 시작하며 실제 플레이 시간이 30초 지날 때마다 **쉬움 → 보통 → 어려움 → 똥 지옥** 순서로 다음 단계가 자동 적용됩니다. 일시정지 시간은 포함되지 않으며 최고 기록은 하나로 통합됩니다.

노클립 모드 아래의 **하드 모드** 토글을 켜면 어려움 단계에서 시작해 20초 뒤 똥 지옥으로 넘어갑니다. 묶음마다 일반 똥이 2개 더 생성되고 낙하 속도와 새의 출현 빈도가 증가하며, 우산 1개와 속도 아이템 2개만 가지고 시작합니다.

게임 중 점수판 아래의 단계 진행 표시에서 현재 난이도, 다음 단계까지 남은 시간과 진행률을 확인할 수 있습니다. 똥 지옥에 도달하면 최종 단계로 표시됩니다.

모든 난이도에서 새가 화면 오른쪽에서 왼쪽으로 날아가며 새똥을 한 번 떨어뜨립니다. 게임은 우산 사용권 3회로 시작합니다. 공중에서 떨어지는 새똥을 먹으면 새똥이 사라지고 사용권이 1회 추가되며, 최대 5회까지 누적됩니다. 게임 중 `Space`를 누르면 사용권 1회를 소비하여 파란 우산이 2초 동안 나타납니다. 이때도 새로운 똥은 계속 떨어지며, 우산에 닿은 일반 똥만 화면 밖으로 튕겨 나갑니다. 우산은 캐릭터 자체를 무적으로 만들지 않습니다.

게임은 속도 아이템 5개로 시작합니다. `Shift`를 누르면 1개를 사용해 2초 동안 이동 속도가 빨라지며, 2인용에서는 두 플레이어가 효과와 사용권을 공유합니다.

우산과 속도 아이템이 1개만 남으면 수량이 주황색으로, 모두 소진되면 빨간색으로 표시됩니다. 소진된 아이템을 사용하려 하면 화면 안내와 짧은 효과음으로 알려주며, 활성 효과가 1초 미만으로 남으면 하단 시간 표시가 깜빡입니다.

플레이 중 일정 간격으로 `⭐` 보호막 아이템이 떨어집니다. 별을 먹으면 캐릭터 주위에 보호막이 생기며 다음 일반 똥 충돌을 한 번 막고 해당 똥을 튕겨냅니다. 2인용에서는 보호막을 공유합니다.

추가 파워업으로 `🧲` 자석과 `🫧` 축소 방울이 무작위로 등장합니다. 자석은 6초 동안 화면의 새똥과 아이템을 플레이어 쪽으로 끌어당기며, 축소 방울은 6초 동안 캐릭터와 충돌 범위를 줄여 좁은 틈을 통과하기 쉽게 만듭니다.

30점을 획득할 때마다 보유 수가 더 적은 우산 또는 속도 아이템을 1개 보급합니다. 두 아이템이 모두 최대치라면 보호막을 충전합니다.

일반 모드는 45점, 하드 모드는 35점 간격으로 다음 묶음에 거대 똥이 한 개 추가됩니다. 거대 똥이 등장하기 전 화면에 경고가 표시되며, 피했을 때의 점수는 다른 일반 똥과 동일하게 1점입니다.

홈 화면의 스피커 버튼이나 `M` 키로 효과음을 켜고 끌 수 있습니다. 카운트다운, 시작, 묶음 회피, 새 등장과 새똥, 아이템 획득, 우산 반사, 속도 증가, 보호막 충돌, 거대 똥 경고, 일시정지, 단계 상승, 게임 오버와 최고 기록에 서로 다른 소리가 적용됩니다. 선택한 설정은 브라우저에 저장됩니다.

지원되는 모바일 기기에서는 아이템 획득, 보호막 방어, 거대 똥 경고와 게임 오버 때 짧은 진동으로 상황을 알려줍니다.

먹지 못한 새똥과 바닥까지 떨어진 일반 똥은 착지하는 즉시 사라집니다. 새똥은 점수에는 포함되지 않습니다.

떨어지는 일반 똥은 바닥에 붉은 낙하 경고를, 우산 사용권을 주는 새똥은 파란 낙하 경고를 표시합니다. 똥이 가까워질수록 경고가 진해집니다.

홈 화면 왼쪽 위의 배경 메뉴에서 **아침, 오후, 저녁, 밤**을 직접 선택할 수 있습니다. 선택한 배경은 브라우저에 저장됩니다.

선택한 배경에는 시간대별 분위기 효과가 적용됩니다. 아침에는 햇빛 먼지, 오후에는 햇빛 번짐, 저녁에는 반딧불이, 밤에는 별똥별이 표시됩니다.

전체 플레이의 최고 기록 하나가 저장되며 홈 화면의 게임 시작 버튼과 게임 종료 화면에서 확인할 수 있습니다.

홈 화면에서 **NOCLIP MODE** 스위치를 켜면 똥과 충돌해도 게임이 종료되지 않습니다. 노클립 점수는 일반 최고 기록에 저장되지 않습니다.

**어려움**과 **똥 지옥**에서는 강풍이 자동으로 활성화됩니다. 일정 시간마다 방향과 세기가 바뀌는 바람이 떨어지는 일반 똥을 좌우로 밀어내며, 게임 화면의 강풍 표시에서 현재 바람 방향을 확인할 수 있습니다.

게임을 시작하는 방법은 다음과 같습니다.

* **게임 시작 버튼을 마우스로 클릭**
* **Space 키 입력**

둘 중 하나를 실행하면 게임이 시작됩니다.

### 2. 게임 화면

게임이 시작되면 외부 헤더와 안내 영역이 사라지고 게임 화면이 브라우저 전체 영역을 채웁니다.

게임 화면에서는 다음과 같은 요소가 표시됩니다.

* 플레이어
* 하늘에서 떨어지는 똥
* 현재 점수

현재 점수판은 게임 화면 상단 중앙에 표시됩니다.
현재 점수가 통합 최고 기록을 넘으면 점수판 옆에 **New Best!** 문구가 표시됩니다.

똥은 현재 단계에 맞는 개수로 화면 상단의 **무작위 위치에서 생성되며, 각 똥은 서로 다른 크기와 속도로 떨어집니다.** 단계가 높을수록 똥 사이의 속도 차이도 커집니다.

플레이어는 좌우로 이동하면서 똥을 피해야 합니다.

플레이 중 `ESC`를 누르면 게임이 일시정지됩니다. 일시정지 화면에는 현재 생존 시간과 점수가 표시됩니다. 일시정지 중 `Space`를 누르면 3초 준비 카운트다운 뒤 안전하게 계속 플레이하고, `R`을 누르면 즉시 재시작하며, `ESC`를 한 번 더 누르면 홈 화면으로 돌아갑니다. 일시정지 화면의 **홈으로 나가기** 버튼으로도 홈 화면에 돌아갈 수 있습니다.

게임 오버 화면에는 이번 판의 점수와 생존 시간이 표시됩니다. 2인용에서는 충돌한 플레이어도 알려주며, `R` 키로 바로 다시 시작할 수 있습니다.

화면 오른쪽 아래의 **전체 화면** 버튼을 누르면 전체화면을 켜거나 끌 수 있습니다.

---

### 3. 점수

일반 똥을 피해서 바닥까지 떨어뜨릴 때마다 점수가 **1점씩 증가**합니다. 새똥은 점수에 포함되지 않습니다.

예시:

```text
일반 똥 1개 회피 → 1점
일반 똥 5개 회피 → 5점
새똥 회피 또는 획득 → 0점
```

게임이 계속될수록 더 많은 똥을 피해야 하므로 높은 점수를 얻기 위해서는 빠른 반응과 정확한 이동이 필요합니다.

---

### 4. 충돌

플레이어가 떨어지는 똥에 **맞거나 스치는 경우 즉시 게임이 종료됩니다.**

충돌이 발생하면:

1. 플레이어의 생존 상태가 종료됩니다.
2. 플레이어의 외형이 **죽은 상태를 나타내는 모습**으로 변경됩니다.
3. 게임 진행이 중지됩니다.
4. 최종 점수가 화면 중앙에 표시됩니다.
5. 점수 위에 **다시 하기** 버튼이 표시됩니다.

---

## ☠️ 게임 오버

게임 오버 화면은 다음과 같은 형태로 구성합니다.

```text
      [ 다시 하기 ]

          12
        SCORE
```

또는 프로젝트 디자인에 맞게 최종 점수가 화면 중앙에 크게 표시될 수 있습니다.

### 다시하기

게임 오버 상태에서는 **다시 하기** 버튼이 표시됩니다.

다시하기는 다음 방법으로 실행할 수 있습니다.

* **다시 하기 버튼을 마우스로 클릭**
* **Space 키 입력**

다시하기가 실행되면 새로운 게임이 시작되며 점수는 **0점으로 초기화**됩니다.

## 🔄 게임 상태

게임은 다음과 같은 상태로 구성합니다.

```text
┌─────────────┐
│  START      │
│  시작 화면   │
└──────┬──────┘
       │ 게임 시작 (클릭 / Space)
       ▼
┌─────────────┐
│   PLAYING   │
│  게임 진행   │
└───┬──────┬──┘
    │ ESC  │ 충돌 ─────────────┐
    ▼      │                   ▼
┌─────────────┐
│   PAUSED    │
│  일시정지    │
└──────┬──────┘        ┌─────────────┐
       ├─ Space → PLAYING
       └─ ESC → START  │   GAME OVER │
                       │  게임 종료   │
                       └──────┬──────┘
                              │ 다시하기
                              ▼
┌─────────────┐
│   PLAYING   │
│ 새로운 게임  │
└─────────────┘
```

## 💩 장애물 시스템

게임 중 똥은 다음과 같은 규칙으로 생성됩니다.

* 쉬움에서는 처음에 똥이 **1개씩**, 10점부터 **2개씩** 생성됩니다.
* 보통에서는 똥이 **2개씩**, 가끔 **3개씩** 더 빠르게 생성됩니다.
* 어려움에서는 더 큰 똥이 **3~5개씩 무작위로 동시에** 생성되며 매우 빠르게 떨어지고 좌우로 흔들립니다.
* 똥 지옥에서는 이전 묶음이 바닥에 닿기 전에 다음 묶음이 생성되며, 성능 저하를 막기 위해 동시에 떨어지는 일반 똥 수를 제한합니다.
* 각 똥은 다른 똥의 위치와 관계없이 화면 상단의 **완전히 무작위인 X 위치**에서 생성됩니다.
* 똥은 위에서 아래 방향으로 이동하며 점수가 높아질수록 빨라집니다.
* 플레이어와 충돌하면 즉시 게임 오버가 됩니다.
* 각 일반 똥이 바닥까지 떨어질 때마다 점수가 1 증가하고 즉시 사라집니다.
* 플레이어가 움직이지 않은 상태로 똥을 3개 이상 피하면 다음 묶음 중 **1개만** 플레이어 머리 위를 겨냥합니다.
* 플레이어가 좌우로 이동하면 겨냥 조건이 초기화되고 다시 무작위 위치에서 생성됩니다.
* 이후 새로운 똥이 생성되어 게임이 계속 진행됩니다.

## 👤 플레이어 시스템

플레이어는 게임 화면 하단에 위치합니다.

### 이동

```text
← ← ←      PLAYER      → → →
```

* 좌우 이동만 가능합니다.
* `A` / `←` : 왼쪽 이동
* `D` / `→` : 오른쪽 이동
* 화면 밖으로 이동할 수 없습니다.

### 사망 상태

똥과 충돌하면 플레이어는 즉시 사망합니다.

사망 시 플레이어의 이미지 또는 캐릭터 상태를 변경하여 게임 오버 상태임을 시각적으로 표현합니다.

예:

```text
생존 상태
   🧍

    ↓ 충돌

사망 상태
   💀
```

## 🎨 디자인 방향

전체적인 게임 분위기는 **간단하고 직관적인 캐주얼 아케이드 게임**을 목표로 합니다.

### 주요 디자인 원칙

* 충돌 및 게임 오버 상태를 즉시 인식할 수 있도록 시각적 효과 적용

## 📌 게임 규칙 요약

1. 게임을 실행하면 시작 화면이 나타납니다.
2. **게임 시작 버튼**을 클릭하거나 `Space`를 누릅니다.
3. 게임이 시작되면 전체 게임 화면에서 똥이 무작위로 떨어집니다.
4. `A` / `←`로 왼쪽, `D` / `→`로 오른쪽으로 이동합니다.
5. 일반 똥 1개를 바닥까지 피할 때마다 **1점**을 획득합니다.
6. 똥에 맞거나 스치면 즉시 게임 오버가 됩니다.
7. 플레이어는 사망 상태로 변경됩니다.
8. 화면 중앙에 최종 점수가 표시됩니다.
9. **다시 하기** 버튼을 클릭하거나 `Space`를 누르면 새로운 게임이 시작됩니다.
10. 일시정지 중 **나가기**를 누르면 홈 화면으로 돌아갑니다.
