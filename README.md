# 💩 Poop Dodge

떨어지는 똥을 피하고, 아이템을 활용하며, 최고 기록에 도전하는 웹 아케이드 게임입니다.

> 🎮 **[브라우저에서 바로 플레이하기](https://lumindr.github.io/Poop-Dodge/)**  
> 설치 없이 PC와 모바일에서 즐길 수 있습니다.

## 게임 방법

1. 1인용 또는 2인용을 선택하고 게임을 시작합니다.
2. 좌우로 움직이며 떨어지는 똥을 피합니다.
3. 일반 똥이 바닥까지 떨어질 때마다 1점을 얻습니다.
4. 30초마다 **쉬움 → 보통 → 어려움 → 똥 지옥** 순서로 난이도가 올라갑니다.
5. 똥에 맞으면 게임이 끝나며 최고 기록이 저장됩니다.

## 주요 특징

| 특징 | 설명 |
| --- | --- |
| 자동 난이도 상승 | 시간이 지날수록 똥의 개수와 속도가 증가합니다. |
| 무작위 낙하 | 똥마다 떨어지는 위치, 크기와 속도가 다릅니다. |
| 하드 모드 | 어려움 단계부터 시작하며 더 적은 아이템으로 버텨야 합니다. |
| 노클립 모드 | 충돌을 무시하고 자유롭게 플레이합니다. 노클립 점수는 최고 기록에 저장되지 않습니다. |
| 2인용 | 한 화면에서 함께 피하며 점수와 아이템을 공유합니다. |
| 특수 위험 요소 | 새와 새똥, 거대 똥, 강풍과 낙하 경고가 등장합니다. |
| 다양한 환경 | 아침, 오후, 저녁과 밤 배경을 직접 선택할 수 있습니다. |
| 편의 기능 | 전체화면, 효과음, 모바일 진동과 최고 기록 저장을 지원합니다. |
| 다국어 | 한국어, 영어, 일본어와 중국어를 지원합니다. |

## 아이템

| 아이템 | 효과 |
| --- | --- |
| `☂` 우산 | 2초 동안 떨어지는 똥을 튕겨냅니다. |
| `⚡` 속도 아이템 | 2초 동안 이동 속도가 빨라집니다. |
| `⭐` 보호막 | 다음 충돌을 한 번 막아줍니다. |
| `🧲` 자석 | 떨어지는 아이템을 플레이어 쪽으로 끌어당깁니다. |
| `🫧` 축소 방울 | 6초 동안 캐릭터와 충돌 범위를 줄입니다. |
| 새똥 | 먹으면 우산 사용권이 1개 추가됩니다. 최대 5개까지 보유할 수 있습니다. |

## 조작 방법

### 키보드

| 입력 | 동작 |
| --- | --- |
| `A` / `D` | 1P 좌우 이동 |
| `←` / `→` | 1인용에서는 1P 이동, 2인용에서는 2P 이동 |
| `Space` | 게임 시작·다시 하기, 우산 사용, 일시정지 해제 |
| `Shift` | 속도 아이템 사용 |
| `ESC` | 일시정지, 홈으로 돌아가기 |
| `R` | 일시정지 또는 게임 오버 중 바로 다시 시작 |
| `M` | 효과음 켜기·끄기 |
| `⛶` 버튼 | 전체화면 켜기·끄기 |

### 2인용

- **1P**: `A` / `D`
- **2P**: `←` / `→`
- 한 명이 똥에 맞으면 게임이 종료됩니다.
- 우산, 속도 아이템과 보호막은 함께 사용합니다.

### 모바일

화면 아래의 `←`, `→`, `⚡`, `☂`, `⏸` 버튼으로 이동, 아이템 사용과 일시정지를 조작할 수 있습니다.
